# Структура реестра

HKLM - настройки всей машины.
HKCU - настройки текущего пользователя.
HKCR - ассоциации файлов.
HKCC - текущий профиль оборудования.
HKU - профили всех пользователей.

Кусты и их файлы на диске (C:\Windows\System32\config):
HKLM\sam - локальные учетные записи, хэши паролей.
HKLM\security - политики безопасности, LSA.
HKLM\software - настройки установленного по.
HKLM\system - параметры загрузки, controlset, драйверы
HKU\.DEFAULT — системный профиль, не шаблон профиля нового пользователя.
HKCU - настройки конкретного пользователя (C:\Users\\"username"\NTUSER.DAT)

Типы данных в реестре:
REG_SZ - строка.
REG_DWORD - 32-битное число.
REG_QWORD - 64-битное число.
REG_BINARY - бинарные данные (хеши, ключи).
REG_MULTI_SZ - массив строк.
REG_EXPAND_SZ - строка с переменными окружения.
