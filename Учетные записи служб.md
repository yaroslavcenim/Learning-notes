# Учетные записи служб

LocalSystem (SYSTEM) — высокопривилегированный локальный контекст. Он не равен Domain Admin и не отменяет все механизмы защиты.
Network Service — машина в сети. Полезно для атак на AD.
Сессия 0 — службы. Сессия 1+ — пользователи.

Посмотреть кто ты:
  whoami /priv
  whoami /user

Посмотреть активные сессии:
  query session
  qwinsta

Процессы с привязкой к сессии: tasklist /v
