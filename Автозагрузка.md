# Автозагрузка

Расположение автозагрузки:
HKLM\software\microsoft\windows\currentversion\run - для всех пользователей
HKCU\software\microsoft\windows\currentversion\run - для текущего пользователя
HKLM\\...\runonce - для всех пользователей (один раз при загрузке)
HKCU\\...\runonce - для текущего пользователя (один раз при загрузке)

Добавление записи в реестр:
reg add hklm\\...\run /v "name" /t REG_SZ /d cmd.exe
