# Службы

Расположение: hklm\system\currentcontrolset\services
Ключевые параметры:
  ImagePath - путь к исполняемому файлу
  Start - тип запуска (0=boot, 1=system, 2=automatic, 3=manual, 4=disabled)

Процессы и службы: tasklist /svc
Процессы и сетевые соединения: netstat -ano
