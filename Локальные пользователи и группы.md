# Локальные пользователи и группы

Пользователи:
net user                                 — список пользователей
net user <имя>                     — информация о пользователе
net user <имя> /add             — создать
net user <имя> /delete         — удалить
net user <имя> *                   — сменить пароль
net user <имя> /active:no    — отключить
net user <имя> /active:yes   — включить

Группы:
net localgroup — список групп
net localgroup <группа> — кто в группе
net localgroup <группа> <имя> /add — добавить в группу
net localgroup <группа> <имя> /delete — удалить из группы
