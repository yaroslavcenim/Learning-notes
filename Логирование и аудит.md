# Логирование и аудит

Чтение событий: wevtutil qe Security
Очистка журнала: wevtutil cl Security

Event ID:
  Входы в систему:
    4624 - успешный вход
    4625 - неудачный вход
    4634 - выход из системы

  Управление пользователями:
    4720 - создан пользователь
    4722 - пользователь включен
    4724 - сброс пароля
    4732 — участник добавлен в локальную группу безопасности (не универсальное событие для всех типов групп)

  Процессы и службы:
    4688 - создан новый процесс
    4697 - служба установлена в системе

  Опасные события:
    1102 - журнал безопасности очищен
    4719 - изменена политика аудита

Событие 4624 (вход)
  Logon Type - тип входа:
    2 - интерактивный (за клавиатурой)
    3 — сетевой (например, SMB); RDP RemoteInteractive — тип 10
    5 - служба
    7 - разблокировка экрана
    10 - RDP
  Account Name - кто вошел
  Source Network Address - IP с которого вошли

wevtutil - чтение и фильтрация
Список всех журналов: wevtutil el
Очистить журнал: wevtutil cl Security

wevtutil qe Security /c:5 /rd:true /f:text
  qe - query events, запросить события
  Security - имя журнала
  /c:5 - count, сколько событий показать
  /rd:true - reverse direction, от новых к старым (true), от старых к новым (false)
  /f:text - format, в каком виде вывести

wevtutil epl Security C:\backup.evtx
  epl - export log
  Security - что экспортируем
  C:\backup.evtx - куда сохраняем

Фильтрация событий:
  Флаг /q: - фильтрует события по критериям
  /q:"* [System[(EventID=4624)]]"
  " * " - любое событие
